## Discovery

- Pi mendeteksi `.pi/skills/` pada **project tepercaya**.
- Saat startup ditampilkan nama/deskripsi; instruksi lengkap dibaca saat dipakai.
- Gunakan `/skill:k6-ask-codebase` (atau nama lain) untuk memuat eksplisit.
- Bila tidak terdeteksi, buka `.pi/skills/<name>/SKILL.md` secara manual.

<Info>
Skill adalah panduan, **bukan bukti** CLI/layanan/credential/index terpasang. Tidak ada
executable helper yang disertakan.
</Info>

## Kontrak operasi bersama

- Minta scope/izin yang hilang, baca file sebelum edit, verifikasi dengan check relevan.
- Jangan mengklaim perintah yang tidak dijalankan berhasil.
- Default Go lokal; k6 smoke nyata; integrasi opt-in; load butuh izin.
- Pertahankan secret, no-redirect, propagasi error/exit, dan guard workload.
- Pisahkan bukti `local` dari `integration`.
- HTML/JSON k6 adalah aggregate, bukan raw sample.
- Ketersediaan Graphify/index bukan bukti repository sudah ter-index.
